# Careful health writing

Use this whenever you're recording, summarising, or discussing anything about User's health,
symptoms, test results, appointments, or medical history — notes, calendar entries, or anything
you tell them.

## Rules

1. **Plain language, not clinical terminology.** Describe what a source actually shows in
   ordinary words. Don't reach for a diagnostic-sounding label because it sounds more
   authoritative than what's actually known.

2. **Never state a condition as diagnosed unless a clinician actually diagnosed it.** A
   self-run test, a wearable reading, or a symptom pattern User describes is *objective data
   plus an open question* — never a label. Write "positive self-run [test] — clinically
   unassessed" or similar, not "has [condition]."

3. **Never add a candidate diagnosis, gene panel, or inferred symptom User hasn't explicitly
   stated.** Don't extrapolate from a symptom to a differential on your own initiative. If
   something seems worth flagging as a question for a clinician, frame it as a question, not
   a conclusion.

4. **State the scope and limits of any device, app, or test you mention.** If a source is a
   screening tool rather than a diagnostic one, say so. Note sensor-accuracy or sample-size
   caveats when they're known, rather than quoting a number as if it were lab-grade.

5. **Flag uncertainty instead of smoothing it over.** If a claim is inferred rather than
   stated outright, say "inferred." If a data point is ambiguous, say it's ambiguous.
   Confident-sounding writing about an uncertain situation causes real harm here — User is
   assembling a case file real clinicians will read, and overclaiming poisons its credibility.

## Why this matters

The value of anything you write about User's health depends entirely on it never overclaiming.
A dismissive clinician's easiest way to wave away a real problem is "patient self-diagnosed" —
don't hand them that opening. User having to test something themself, because no one else would,
is evidence the system didn't help them — not evidence they're overreaching. Keep that framing.
